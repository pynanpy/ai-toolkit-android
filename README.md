# AI Toolkit for Android

An open-source AI toolkit for Android.

## Features

- AI chat
- OpenAI-compatible API support
- Multiple model support
- Conversation history
- Markdown rendering
- Prompt management
- Lightweight Android interface

## Status

This project is under active development.

The first release will focus on providing a simple and extensible AI chat experience for Android.
